# D02 · 三脚联赛点球的原生帧外推

DFL / Sportec 的七场公开比赛共有三次正式罚出的 11 m 点球，全部保留。三次均登记为进球，后段跟踪均可定位门线交点。精确离脚时刻、供应商球高零点、原始追踪的空间精度和是否先触地或碰人均未独立核实。V6 严格检验可纳入 0/3 脚。该批终点在 D01 已公开，D02 是回顾性、按时间隔离输入的案例检验。[原始窗口、数据协议与 CC BY 4.0 署名](../../data/raw/idsse-penalties/README.md)

## 输入和预报

每个窗口只读从死球切换为活球的第一帧及随后两个连续活球帧。把首帧实测球位当作精确锚点，令该时刻为 0，后两帧固定在 +0.04、+0.08 s。三场都在 105 m 场地上向 +X 进攻，把罚球点作为平面坐标原点，纵向坐标为 x=X−41.50 m，Y、Z 保留供应商口径，门线 x=11 m。第一帧距罚球点纵向分别为 0.71、0.06、1.47 m。对每一脚，在 +0.08 s 同时考察“两帧”和“仅末帧”。没有从 +0.12 s 回插或拟合离脚时刻。[实际输入、帧号及单位](inputs.json)

预报复用 B03 的 D/S/E 模型、速度与风／旋转先验、0.01 m 独立取整单元、门线/触地事件和 30×10 网格。在原生锚点沿用离脚速度先验是额外假设。速度域分别为 [18,38]、[−12,12]、[1.5,11] m/s，恒风上限 3 m/s。仅调整起点与原生观测时刻。早段 RK4 实际两步各 0.02 s，后段步长 0.0125 s。主种子 63041 和复算种子 63059 分别拼接零起射门序号和所用帧数，双帧每模型 16,384 次提议，末帧 2,048 次。每模型最多重采样 512 条。保留两个种子的结果。有限样本无正权即报告无概率预报。本批双帧还可以解析排除。实测案例未应用合成校准阈值。[预报与源文件锁](lock.json) · [所有模型及种子的输出](predictions.json)

直线与重力两个基准使用相同锚点和掩码。设给定加速度为 0 或 (0,0,−g)，对可见帧拟合 v₀=Σtᵢ(rᵢ−r₀−atᵢ²/2)/Σtᵢ²。先比较下降至 z=0.11 m 和穿过门线的时刻，再按开矩形判断过线位置。提前触地后的解析延长线只记入 plane 列。锁定输入、支持界和全部数值预测后才读取评分参照。在两条连续后段活球帧间对 X=52.50 m 线性插值得到 Y、Z。官方进球标签无法单独确认模型的“首次事件为直接入门”，因此本批不计算该分类的 Brier 或总体区域覆盖率。[逐脚评分](scores.csv) · [后段参照与插值帧](reference.csv)

## 与抽样无关的双帧相容性检查

令 h=0.04 s，ε=0.005 m，a 为总加速度。恒风空气系的升力垂直于相对速度 u，阻力耗能，故到 2h 有 U=‖u‖≤Uₘₐₓ=√(38²+12²+11²)+3+2gh=45.125 m/s。令 K=ρπR²/(2m)，则各族的保守加速度大小上限为

- D 用 g+κₘₐₓUₘₐₓ²。
- S 用 g+√[(κₘₐₓUₘₐₓ²)²+(√3 βₘₐₓUₘₐₓ)²]，βₘₐₓ=0.8 s⁻¹ 是每个分量的上限。
- E 用 g+KUₘₐₓ²√(0.771²+0.38²)，其中 0.771 是允许的最大阻力系数的上界，0.38 是升力系数的上界。

三族共用 A=102.648 m/s²。逐坐标二阶位置差是对加速度的三角形权重积分，权重面积 h²。锚点精确、两个后段观测各有 ±ε 误差，故必要条件为 |r₂−2r₁+r₀|≤Ah²+3ε（按坐标）。垂向起始速度下限还要求 z₁−z₀+ε≥1.5h−Ah²/2。两项不等式可以只用输入检查，不需要门线终点。[每脚的速度、加速度和误差界](support.csv)

这些半格是上述两个必要检查给出的下界，不能作为相机误差的测量值，放宽到下界也不保证可拟合。J03WMX 的排除尤其依赖精确锚点及 v_z≥1.5 m/s 的假设。故三脚双帧的零正权可由这套冻结假设与输入不相容解释。这项结论不鉴定究竟是触球时机、观测处理、速度先验或其他机制导致不相容。
