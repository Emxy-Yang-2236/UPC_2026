# 两帧点球预测的稳定旋转球留出试验 Z10

Z09 在共同 90% 校准目标下，带噪双帧预测在直接入门的稳定旋转球上命中 12/23，重力为 21/23；另两组各命中 24/24。这批数据只提出问题。本试验用独立合成射门检验这个分组差异是否复现，并测量改升力先验、改善坐标和改变校准时各自付出的面积代价。题面点球仍使用 50、100 ms 两次观测，所有可部署方法在 100 ms 截止。

## 样本、模型和盲法

从 B-1.0 配置和已归档的三族参考力律生成 300 脚校准、600 脚独立留出。每三脚随机排列无旋、稳定旋转、低旋尾流三族。真值速度、风、旋转和气动系数逐脚独立抽取。稳定族角速度分量均匀分布于 ±55 rad/s，方向固定，升力系数含衰减。使用独立标量自适应 DOP853，首达球门或落地时停。新真值、坐标噪声和推断种子见同包配置。旧 Z09 和题面算例不参与校准、选择和评分。用相同物理射门制作纯 1 cm 取整和先加 6 mm 逐帧独立高斯误差、8 mm 双帧共享高斯误差再取整的两种读数。释放锚点及时间精确。

先锁定设计版本。真值表与逐脚可见观测分开，预测入口只接收两帧位置和随机数。阈值只能从校准真值确定，按 90% 有限样本秩 ceil(0.9(n+1)) 选取，超出校准样本时返回整个球门的阈值。留出真实结果仅在全部预测和阈值写入、计算 SHA-256 后打开评分。整脚为统计单位。不把两种读数、采样重复或三个预测轴算成独立射门。

## 固定对照与解释范围

| 预先规定的对照 | 唯一更改及可回答的问题 |
| --- | --- |
| 复验 | 在新样本中对三族分别报告带噪双帧气动、双帧重力在共同 90% 目标下的命中/分母、Wilson 区间、面积及误差。点误差对有点估计的入门射门计算，注明分母。 |
| 升力先验 | 同一带噪输入及采样预算，比较原模型、S 的每分量有效升力参数和 E 的每分量角速度先验半宽同时乘 0.5 或 1.5，及只改变 D/S/E 混合权重从 0.2/0.4/0.4 至 0.02/0.49/0.49。权重对照复用相同模型内样本。E 的饱和升力关系保持原式。各方案各自用整池校准；同时报告固定原阈值下的效果、真值格的分数和点误差，辨认校准与分布排序各自的变化。 |
| 观测与曲率 | 同一射门在两种读数上使用各自匹配的似然和提议宽度，比较原模型与重力。以无噪连续真值作诊断，计算 y、z 两轴二阶差分加速度 (r2−2r1+r0)/h²，h=0.05 s。按族报告逐轴 RMSE、合并 RMSE 及每脚两轴误差模长。参考方差为 (5σ²+τ²+5q²/12)/h⁴，其中独立均匀取整仅为近似。用相同带噪末帧及精确起点，另做固定加速度对照：只将带噪二阶差分替换为取整前真值二阶差分，重新解前向过线和首次触地。这个诊断使用额外真值，只衡量曲率误差的传播。 |
| 校准 | 在相同带噪原模型的冻结格概率上比较四种阈值：全体入门校准、按已知族别校准（机制诊断）、各族阈值最大值用于所有球（推断只需两帧）、按可见弯曲信号分两层校准。信号为 norm((a_y,a_z+g))/s，其中 s 是上述带噪单轴理论标准差；预先固定边界 2。并列面积、点和格排序，避免把放大区域等同于改善落点。三种逐组阈值法均只以校准集入门球拟合。 |
| 数值验证 | 对盲测 ID 的前 48 脚用第二推断种子重算带噪原模型，固定第一种子的校准阈值，报告两次格心差异、命中变化和低 ESS 数。分别与存档 Z09 计数、重力解析轨迹和至少三脚高精度参考交叉核对。 |

## 输出与判断

所有气动组每模型使用 8,192 个重要性提议，至多 512 条传播样本。每脚同一推断流，所有组同一 30×10 球门网格。点采用最高概率格心（重力为连续交点），区域用原文的格排序分数或重力距离分数。无点和无分布的预测单独计数；无分布的入门球计区域漏失、面积零。所有事件用可用概率计算 Brier 并给出分母，点、区域面积和覆盖专门给直接入门球。每项结果必须带方法、读数、校准方式和入门分母，报告阈值达到 1 对应的整门面积 17.8608 m²。对稳定旋转球的主要效应使用 4,000 次整脚配对自助区间（百分点、m²、m），并给两种方法互有得失的脚数。区间条件于本次校准集；多项诊断为探索性比较。

若新样本出现相同方向的分组差距，报告其量级及不确定性。先验干预看相同读数下的排序和点位能否恢复；测量干预看真实二阶差分误差及点预测能否同步改善；校准干预看同一分布在怎样的面积代价下恢复覆盖。若结果交叠，保留多种解释。本试验只对既定参考力律和合成测量条件作推断，真实球型、转速与同步过线观测仍需独立采集。

## 接手与复算

科学 Python 需 NumPy、SciPy。根目录的执行入口为 `python experiment/src/stable_spin.py --out scratch/Z10-replay --workers 4`。输入是本包两份 JSON 和上述参考力律；按配对顺序生成观测，分层不能进入主预测器，输出分为观测与真值、锁定的分布、阈值、逐脚评分及汇总。先在独立目录按已冻结配置运行，再从逐脚表复核计数、面积和区间。程序及锁定证据在执行阶段交接。
