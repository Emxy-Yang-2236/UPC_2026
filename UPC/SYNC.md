# UPC 同步约定

授权目标为 https://github.com/Emxy-Yang-2236/UPC_2026 ，工作区分支为 `zhaohaoyang`，本地 UPC 文件夹映射为仓库的 `UPC/`。该分支基于研究分支 research/2026-b 的提交 `8161c175a8638cdfff1a5d41b103d8d4bd11c56d`。原 main 和技能开发分支保留。

当前工作副本为 `UPC_2026/`。先获取远端更新并检查差异，再将新内容合入本地研究目录，避免用旧本地快照覆盖其他成员的提交。存在冲突时保留双方版本。

本地准备命令为 `python sync_workspace.py`。它复制当前 UPC 内容到工作副本的 `UPC/`，生成逐文件 SHA-256 与 Git blob 哈希清单。它不会删除远端已有文件，也不会自行推送。文件删除需要单独审查并与远端对齐。

纳入题面、研究材料、实验代码、计算输出、报告、旧技能副本与备份。排除 `.git`、Python 缓存、虚拟环境、同步工作副本和 `_sync` 临时材料。明显凭据文件及疑似访问令牌会使准备步骤停止，报告路径而不打印凭据。

本机原生 Git 当前没有可用于 push 的登录凭据，因此发布使用已连接的 GitHub 工具。文本和二进制文件均保持原始字节，在创建提交后核对远端 tree 与清单。远端更新时重新获取，禁止直接覆盖未知更新。

后续由本项目中的代理在每轮有意义的更新后执行同步并报告提交号。目前没有设置后台监听或定时上传。其他人手工编辑的内容需在后续工作时执行相同同步流程。

实验区入口为 `experiment/README.md`，报告区入口为 `report/README.md`，待办扫描记录为 `report/workspace-scan.md`。未找到原始 `next-step.md` 时保持缺失状态，不将新写的研究计划冒充用户待办。

当前活动研究位于本地 UPC_2026/experiment、UPC_2026/report、UPC_2026/paper。研究仓库根目录的实验与报告为准，UPC/ 快照中的旧资料作为历史背景。实际待办文件为 UPC_2026/report/next-steps.md。
