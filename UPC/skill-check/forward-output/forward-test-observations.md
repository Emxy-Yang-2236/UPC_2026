## Friction and failures observed

1. **Scope/metadata overhead, skill workflow:** At the start of this run, the default full-project path led to six evidence CSVs and many module/reference reads for a one-equation calculation. The schema worked, but metadata exceeded the substantive calculation in size. A lightweight practice path is useful. The coordinator subsequently reported adding one; this run does not independently validate that amendment.
2. **Practice-rule routing, skill workflow:** Several references begin with actual-contest rule checks. A clearly invented practice problem required a scope decision to mark contest-only requirements not applicable rather than browsing or inventing team fields. No actual rule-verification claim was made.
3. **Inline math, generated-artifact/execution defect:** Some initial inline delimiters lost backslashes in a JavaScript command string and left raw TeX commands in ordinary parentheses. A coordinator spot-check caught the defect. It was repaired using Markdown dollar delimiters and checked in the saved source, including all six table rows and preservation of prose parentheses. At the start of the run the skill lacked an explicit Markdown-inline-delimiter check; the coordinator reported adding one afterward. The immediate defect was in generated output/escaping, not physics or an operating-system failure.
4. **Rounded display checker, execution defect:** An initial ad hoc source checker used exact float equality between displayed 13.2 and stored 13.200000000000001. The calculation itself and output reproducibility had passed. The checker was corrected to compare the chosen display precision; no physics results changed. The history is preserved in the reproduction note.
5. **AI transcript coverage, environment/integration limitation:** No genuine full-session export was available to this bounded agent. Exact received task inputs and generated artifacts are retained, but they are not a complete interaction transcript. The skill's incomplete-coverage fallback was used honestly; no synthetic complete AI report was fabricated.

There were no blocked tool calls, missing dependencies, solver failures or environmental installation issues. The bundled Python 3.12.14 and standard library sufficed. No claim is made that a source-only Markdown inspection is rendered-layout QA.
