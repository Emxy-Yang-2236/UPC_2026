# B 题整合稿论证提纲

| 章节 | 回答的问题 | 核心证据与边界 |
| --- | --- | --- |
| 1 飞行几何 | 题目要求怎样落实到输出？两帧已能排除哪些受力条件？ | 题意与格心答案、三维受力图、纯阻力风界、允许 3 m/s 风及 5 mm 取整时的弦法向加速度与非阻力峰值下界 |
| 2 模型与推断 | 如何由力学得到概率预测？ | D/S/E、力学量级、能量关系、重要性权重、事件和网格、ESS |
| 3 题面答案 | 从哪里入门，误差怎样表述？ | (2.56, 2.07) m 格心、0.357 m² 六格区、到时；条件物理参数、边界质量及先验/网格依赖 |
| 4 预测下界 | 两帧为何不能唯一决定终点？ | 精确穿过中心的轨迹对给出 4.38 和 6.99 cm 下界；两脚读数按厘米相同时交点相距 0.922 m，下界 0.461 m |
| 5 观测和因素 | 哪些假设最能改变条件预测？ | 取整/共享误差/时差似然，二阶差分放大，气动到时在共享 ±1 ms 下的区间、均值/热点/无条件入门概率及低 ESS |
| 6 固定截止验证 | 提前一帧在什么条件下有帮助？ | Z09 同批、同预算、100 ms 对照，覆盖–面积曲线、独立校准、重力基线和稳定旋球独立复验；比较先验、曲率与校准，并检验跨批阈值 |
| 7 适用范围 | 哪些结论能用于早期预测？ | 真实第二帧后的剩余时间、同输入单帧实测对照、严格双帧现场验证的缺口 |
| 结论 | 题面射门从何处入门，预测有何限制？ | 条件点和区域、见证轨迹下界、不同测量条件下的比较 |
| 附录 A–C | 如何复算扰动、运行时间与模型？ | 门线事件微分、联合角点试验、分层与耗时、伪代码和物理检查 |
| 附录 D–F | 早期仿真、等待代价和现场记录支持什么？ | 真值生成与早期比较、100/150 ms、25 Hz 加速度相容性和纳入情况 |
| 附录 G | 怎样用真实罚球检验预测？ | 现有跟踪数据的时间分辨率、独立过线测量与采集协议 |
| 附录 H | 稳定旋转球的预测误差来自哪里？ | 二阶差分的噪声放大、升力与自旋先验对照、同一预测图的阈值交换 |
| 附录 I | 如何复现论文？ | 随附输入、锁定预测及匿名的复现说明 |
